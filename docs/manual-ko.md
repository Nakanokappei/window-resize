## 초기 설정

### 손쉬운 사용 권한 부여

Window Resize는 macOS 손쉬운 사용 API를 사용하여 윈도우를 감지하고 크기를 조절합니다. 앱을 처음 실행할 때 권한을 부여해야 합니다.

1. **Window Resize**를 실행합니다. 손쉬운 사용 접근 권한을 요청하는 시스템 대화상자가 나타납니다.
2. **"설정 열기"**를 클릭합니다(또는 직접 **시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용**으로 이동합니다).
3. 목록에서 **"Window Resize"**를 찾아 토글을 켭니다.
4. 앱으로 돌아오면 메뉴 막대에 아이콘이 나타나고 앱을 사용할 준비가 됩니다.

> **참고:** 대화상자가 나타나지 않는 경우 앱의 설정 창에서 직접 손쉬운 사용 설정을 열 수 있습니다([손쉬운 사용 상태](#손쉬운-사용-상태) 참조).

## 스냅 크기 조절

### 작동 방식

Window Resize는 윈도우 크기 조절 작업을 실시간으로 모니터링합니다. 윈도우의 가장자리나 모서리를 드래그하여 크기를 조절하면, 앱이 윈도우 크기가 프리셋 크기에 얼마나 가까운지 감지합니다.

1. **크기 조절 시작** — 평소처럼 윈도우의 가장자리나 모서리를 드래그합니다.
2. **오버레이 표시** — 윈도우 크기가 프리셋에 가까워지면(30픽셀 이내) 윈도우 주위에 색상 테두리 오버레이가 나타나며 대상 프리셋 크기를 보여줍니다.
3. **놓으면 스냅** — 마우스를 놓으면 윈도우가 프리셋 크기에 정확하게 맞춰집니다.
4. **취소** — 마우스를 놓기 전에 윈도우 크기를 프리셋에서 멀리 이동하면 오버레이가 사라지고 스냅이 발생하지 않습니다.

### 이동 스냅

윈도우를 화면 가장자리나 모서리로 드래그하여 위치에 스냅합니다:

- **가장자리 스냅** (좌/우) — 높이를 채우고 너비를 유지합니다
- **가장자리 스냅** (상/하) — 너비를 채우고 높이를 유지합니다
- **모서리 스냅** — 모서리에 윈도우를 배치하고 두 치수를 모두 유지합니다

### 화면비 표시

크기 조절 중 현재 화면비가 오버레이에 표시됩니다. 비율이 잘 알려진 비례에 해당하면 이름이 표시됩니다:

- **황금비** (1.618:1)
- **백은비** (2.414:1)
- **백금비** (1.325:1)
- **청동비** (3.303:1)

다른 비율은 약분된 분수로 표시됩니다(예: "16:9", "4:3").

> 이 기능은 설정에서 끌 수 있습니다([외관 탭](#외관-탭) 참조).

### Shift로 화면비 고정

크기 조절 중 **Shift** 키를 누르고 있으면 화면비가 고정됩니다. 드래그하는 동안 윈도우가 현재 비율을 유지합니다.

> 이 기능은 설정에서 끌 수 있습니다([외관 탭](#외관-탭) 참조).

## 키보드 단축키

모든 키보드 단축키는 설정의 단축키 탭에서 완전히 사용자 정의할 수 있습니다. 기본값:

### 빠른 프리셋

**Control+Option+1**부터 **Control+Option+9**까지 눌러 최전방 윈도우를 즉시 이름이 지정된 프리셋으로 크기를 조절합니다. 중앙에 HUD가 잠시 나타나 프리셋 이름과 크기를 보여줍니다.

| 단축키 | 기본 프리셋 |
|--------|------------|
| Control+Option+1 | Writing (1280 x 800) |
| Control+Option+2 | Reading (900 x 1200) |
| Control+Option+3 | Browsing (1440 x 900) |
| Control+Option+4 | Sidebar (720 x 900) |
| Control+Option+5 | Preview (1920 x 1080) |

빠른 프리셋은 설정의 일반 탭에서 편집할 수 있습니다(라벨, 크기, 단축키). 최대 9개의 프리셋이 지원됩니다.

### 점진적 크기 조절

최전방 윈도우를 키 입력당 10픽셀씩 크기를 조절하며, 윈도우는 중앙에 유지됩니다:

| 단축키 | 동작 |
|--------|------|
| Control+Option+Right | 너비 증가 (+10px) |
| Control+Option+Left | 너비 감소 (-10px) |
| Control+Option+Up | 높이 증가 (+10px) |
| Control+Option+Down | 높이 감소 (-10px) |

### 정밀 모드

1픽셀 조정을 위해 Shift를 누르세요:

| 단축키 | 동작 |
|--------|------|
| Control+Option+Shift+Right | 너비 증가 (+1px) |
| Control+Option+Shift+Left | 너비 감소 (-1px) |
| Control+Option+Shift+Up | 높이 증가 (+1px) |
| Control+Option+Shift+Down | 높이 감소 (-1px) |

### 실행 취소 / 다시 실행

| 단축키 | 동작 |
|--------|------|
| Control+Option+Z | 마지막 크기 조절 실행 취소 |
| Control+Option+Shift+Z | 다시 실행 |

각 윈도우는 자체 실행 취소/다시 실행 기록을 유지합니다.

### HUD 피드백

키보드 단축키를 사용하면 대상 윈도우에 중앙 HUD 필이 나타납니다:

- **빠른 프리셋:** 프리셋 이름(예: "Writing")과 아래에 크기(예: "1280 x 800")를 보여줍니다
- **점진적 크기 조절:** 현재 크기를 보여줍니다(예: "1290 x 800")
- **실행 취소:** "Restored"와 복원된 크기를 보여줍니다

HUD는 0.8초간 표시된 후 사라집니다.

## 설정

메뉴 막대에서 설정을 엽니다: Window Resize 아이콘을 클릭한 다음 **"설정..."**을 선택합니다.

설정은 4개 탭으로 구성됩니다: **일반**, **외관**, **단축키**, **프리셋**.

### 일반 탭

#### 빠른 프리셋

키보드 단축키(Control+Option+1-9)로 적용할 수 있는 최대 9개의 빠른 프리셋을 구성합니다. 각 프리셋에는:

- **단축키** — 단축키 필드를 클릭하여 새 키 조합을 녹음합니다
- **라벨** — 설명적 이름(예: "Writing", "Coding")
- **크기** — 픽셀 단위의 너비와 높이

프리셋을 추가하려면 하단의 라벨, 너비, 높이 필드를 채우고 **"추가"**를 클릭합니다. 프리셋을 제거하려면 옆의 X 버튼을 클릭합니다.

#### 로그인 시 실행

**"로그인 시 실행"**을 활성화하면 macOS에 로그인할 때 Window Resize가 자동으로 시작됩니다.

#### 언어

드롭다운에서 앱의 표시 언어를 선택합니다. 16개 언어 중 선택하거나 **"시스템 기본값"**을 선택하여 macOS 시스템 언어를 따르도록 설정할 수 있습니다. 언어를 변경하면 앱을 다시 시작해야 적용됩니다.

#### 손쉬운 사용 상태

손쉬운 사용 권한의 현재 상태를 나타내는 상태 표시기가 있습니다:

| 표시기 | 의미 |
|--------|------|
| 초록색 | 권한이 활성 상태이며 정상적으로 작동 중입니다. |
| 주황색 | 권한이 부여되었지만 더 이상 유효하지 않습니다([오래된 권한 수정](#오래된-권한-수정) 참조). |
| 빨간색 | 권한이 부여되지 않았습니다. |

### 외관 탭

스냅 오버레이의 시각적 스타일을 설정합니다:

- **크기 조절 테두리** — 크기 조절 시 표시되는 테두리 색상과 선 스타일. 9가지 색상(빨간색, 주황색, 노란색, 초록색, 시안, 파란색, 보라색, 흰색, 회색)과 4가지 스타일(없음, 실선, 점선, 애니메이션) 중 선택. 기본값: 흰색, 애니메이션.
- **스냅 테두리** — 윈도우가 프리셋에 맞춰졌을 때 표시되는 테두리. 기본값: 흰색, 실선.
- **화면비 표시** — 오버레이에서 화면비 라벨을 표시할지 전환합니다. 기본값: 켬.
- **Shift로 비율 고정** — 크기 조절 중 Shift 키로 화면비를 고정할지 전환합니다. 기본값: 켬.

### 단축키 탭

모든 키보드 단축키가 2열 그리드에 표시되며 개별적으로 사용자 정의할 수 있습니다:

1. 동작 옆의 단축키 필드를 클릭합니다.
2. 원하는 키 조합을 누릅니다(수정자 키가 하나 이상 포함되어야 합니다).
3. **Escape**를 눌러 녹음을 취소합니다.

앱의 다른 동작과 충돌하는 단축키를 녹음하면 **교체**(단축키 재할당) 또는 **취소**를 제안하는 경고 대화상자가 나타납니다.

알려진 시스템 단축키(Mission Control, Spotlight 등)와 충돌하는 단축키 옆에 경고 아이콘이 나타납니다.

**"기본값으로 재설정"**을 클릭하면 모든 단축키가 원래 바인딩으로 복원됩니다.

### 프리셋 탭

프리셋 탭에는 18개의 기본 제공 프리셋 크기가 픽셀 면적 순(작은 것부터 큰 것까지)으로 표시됩니다. 각 프리셋에는 활성화/비활성화 토글이 있습니다:

- **활성화** — 프리셋이 크기 조절 시 스냅 감지에 사용됩니다
- **비활성화** — 프리셋이 스냅 감지에서 제외됩니다(50% 불투명도로 표시)

기본 제공 프리셋은 삭제할 수 없으며 비활성화만 가능합니다. 기본적으로 6개의 Mac 전용 프리셋(MacBook Air/Pro 디스플레이 크기)이 비활성화되어 있고, 12개의 범용 프리셋이 활성화되어 있습니다.

헤더에 현재 활성화된 프리셋 수가 표시됩니다(예: "12 of 18 enabled").

## 문제 해결

### 오래된 권한 수정

주황색 상태 표시기 또는 "손쉬운 사용: 갱신 필요" 메시지가 표시되면 권한이 만료된 것입니다. 이는 앱이 업데이트되거나 다시 빌드된 후에 발생할 수 있습니다.

**수정 방법:**

1. **시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용**을 엽니다.
2. 목록에서 **"Window Resize"**를 찾습니다.
3. 토글을 **끄고** 다시 **켭니다**.
4. 또는 목록에서 완전히 제거한 후 앱을 다시 실행하여 다시 추가합니다.

### 스냅이 작동하지 않음

크기 조절 중 오버레이가 나타나지 않는 경우:

- 손쉬운 사용 권한이 활성 상태인지 확인합니다(설정에서 초록색 표시기 확인).
- 크기를 조절하려는 윈도우가 표준 크기 조절을 지원하는지 확인합니다(일부 앱은 윈도우 크기 조절을 제한합니다).
- 전체 화면 윈도우는 크기를 조절할 수 없습니다 — 먼저 전체 화면을 종료하세요.
- 프리셋 탭을 확인하세요 — 대상 크기가 비활성화되어 있을 수 있습니다.

### 스냅 후 윈도우 렌더링 문제

드물게 스냅 후 대상 윈도우가 제대로 다시 그려지지 않을 수 있습니다. 앱이 자동으로 다시 그리기를 시도하지만, 시각적 이상이 지속되면 윈도우를 최소화했다가 복원해 보세요.
