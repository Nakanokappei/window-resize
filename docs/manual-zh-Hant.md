## 初始設定

### 授予輔助使用權限

Window Resize 使用 macOS 輔助使用 API 來偵測和調整視窗大小。首次啟動時需要授予權限。

1. 啟動 **Window Resize**。系統會彈出對話框，要求您授予輔助使用存取權限。
2. 點擊 **"Open System Settings"**（或手動前往 **System Settings > Privacy & Security > Accessibility**）。
3. 在列表中找到 **"Window Resize"**，打開開關。
4. 返回應用程式——選單列圖示將出現，應用程式即可使用。

> **注意：** 如果對話框未出現，您可以從應用程式的設定視窗直接打開輔助使用設定（請參閱[輔助使用狀態](#輔助使用狀態)）。

## 吸附調整大小

### 運作方式

Window Resize 會即時監控視窗的調整大小操作。當您拖曳視窗邊緣或角落來調整大小時，應用程式會偵測視窗尺寸與預設大小的接近程度。

1. **開始調整大小** — 像平常一樣拖曳任何視窗的邊緣或角落。
2. **覆蓋框出現** — 當視窗大小接近某個預設大小（在 50 像素範圍內）時，視窗周圍會出現彩色邊框覆蓋框，顯示目標預設大小。
3. **放開滑鼠以吸附** — 鬆開滑鼠，視窗即會精確吸附到該預設大小。
4. **取消** — 如果在放開滑鼠前將視窗大小移離預設範圍，覆蓋框會消失，不會進行吸附。

### 長寬比顯示

調整大小時，覆蓋框中會顯示目前的長寬比。當比例與知名比例相符時，會顯示其名稱：

- **√2** (1.414:1)
- **黃金比例** (1.618:1)
- **白銀比例** (2.414:1)
- **塑性比例** (1.325:1)
- **青銅比例** (3.303:1)

其他比例則以簡化分數顯示（例如 "16:9"、"4:3"）。

> 此功能可在設定中關閉（請參閱[外觀標籤頁](#外觀標籤頁)）。

### Shift 鍵鎖定長寬比

調整大小時按住 **Shift** 鍵即可鎖定長寬比。拖曳時視窗會維持目前的比例。

> 此功能可在設定中關閉（請參閱[General 標籤頁](#general-標籤頁)）。

## 鍵盤快速鍵

所有鍵盤快速鍵均可在設定的 Shortcuts 標籤頁中自訂。預設值：

### Quick Presets

按 **Control+Option+1** 至 **Control+Option+9** 可立即將最前方視窗調整為指定的預設大小。置中 HUD 會短暫顯示預設名稱和大小。

| 快速鍵 | 預設 |
|----------|---------------|
| Control+Option+1 | Writing (1280 x 800) |
| Control+Option+2 | Reading (900 x 1200) |
| Control+Option+3 | Browsing (1440 x 900) |
| Control+Option+4 | Sidebar (720 x 900) |
| Control+Option+5 | Preview (1920 x 1080) |

Quick Presets 可在設定的 General 標籤頁中編輯（名稱、大小和快速鍵）。最多支援 9 個預設。

### 逐步調整

每次按鍵調整最前方視窗 10 像素，保持視窗置中：

| 快速鍵 | 操作 |
|----------|--------|
| Control+Option+Right | 增加寬度 (+10px) |
| Control+Option+Left | 減少寬度 (-10px) |
| Control+Option+Up | 增加高度 (+10px) |
| Control+Option+Down | 減少高度 (-10px) |

### 精確模式

按住 Shift 進行 1 像素調整：

| 快速鍵 | 操作 |
|----------|--------|
| Control+Option+Shift+Right | 增加寬度 (+1px) |
| Control+Option+Shift+Left | 減少寬度 (-1px) |
| Control+Option+Shift+Up | 增加高度 (+1px) |
| Control+Option+Shift+Down | 減少高度 (-1px) |

### 復原 / 重做

| 快速鍵 | 操作 |
|----------|--------|
| Control+Option+Z | 復原上次調整 |
| Control+Option+Shift+Z | 重做 |

每個視窗維護各自的復原/重做歷史記錄。

### HUD 回饋

使用鍵盤快速鍵時，目標視窗中央會出現膠囊形 HUD：

- **Quick Preset：** 顯示預設名稱（如 "Writing"），下方顯示大小（如 "1280 x 800"）
- **逐步調整：** 顯示目前大小（如 "1290 x 800"）
- **復原：** 顯示 "Restored" 及還原後的大小

HUD 顯示 0.8 秒後淡出。

## 設定

從選單列打開設定：點擊 Window Resize 圖示，然後選擇 **"Settings..."**。

設定分為 4 個標籤頁：**General**、**Appearance**、**Shortcuts** 和 **Presets**。

### General 標籤頁

#### Quick Presets

設定最多 9 個 Quick Presets，可透過鍵盤快速鍵（Control+Option+1-9）套用。每個預設包含：

- **快速鍵** — 點擊快速鍵欄位以錄製新的組合鍵
- **名稱** — 描述性名稱（如 "Writing"、"Coding"）
- **大小** — 寬度和高度（以像素為單位）

要新增預設，請在底部欄位中填入名稱、寬度和高度，然後點擊 **"Add"**。要刪除預設，請點擊旁邊的 X 按鈕。

#### 登入時啟動

打開 **"Launch at Login"** 開關，可讓 Window Resize 在您登入 macOS 時自動啟動。

#### Shift 鍵鎖定比例

切換按住 Shift 鍵時是否鎖定長寬比。預設值：開啟。

#### 輔助使用狀態

狀態指示器顯示輔助使用權限的目前狀態：

| 指示器 | 含義 |
|--------|------|
| 綠色 | 權限已啟用且運作正常。 |
| 橘色 | 權限已授予但已失效（請參閱[修復失效權限](#修復失效權限)）。 |
| 紅色 | 權限尚未授予。 |

### 外觀標籤頁

設定吸附覆蓋框的視覺樣式：

- **調整大小邊框** — 調整大小時顯示的邊框顏色和線條樣式。可從 9 種顏色（紅色、橘色、黃色、綠色、青色、藍色、紫色、白色、灰色）和 4 種樣式（無、實線、虛線、動畫）中選擇。預設值：橘色、動畫。
- **吸附邊框** — 視窗吸附到預設時顯示的邊框。預設值：橘色、實線。
- **顯示長寬比** — 切換覆蓋框中長寬比標籤的顯示。預設值：開啟。

### Shortcuts 標籤頁

所有鍵盤快速鍵以 2 欄網格顯示，可逐個自訂：

1. 點擊任意操作旁邊的快速鍵欄位。
2. 按下所需的組合鍵（必須包含至少一個修飾鍵）。
3. 按 **Escape** 取消錄製。

如果您錄製的快速鍵與應用程式中其他操作衝突，會出現警告對話框，提供 **Replace**（重新指派快速鍵）或 **Cancel** 選項。

與已知系統快速鍵（Mission Control、Spotlight 等）衝突的快速鍵旁會顯示警告圖示。

點擊 **"Reset to Defaults"** 可將所有快速鍵還原為預設值。

### Presets 標籤頁

Presets 標籤頁顯示 18 個內建預設大小，按像素面積排序（從小到大）。每個預設有啟用/停用開關：

- **已啟用** — 該預設用於調整大小時的吸附偵測
- **已停用** — 該預設被排除在吸附偵測之外（以 50% 不透明度顯示）

內建預設無法刪除，只能停用。預設情況下，6 個 Mac 專用預設（MacBook Air/Pro 顯示器大小）被停用，12 個通用預設被啟用。

頁首顯示目前啟用的預設數量（如 "12 of 18 enabled"）。

## 疑難排解

### 修復失效權限

如果您看到橘色狀態指示器或 "Accessibility: Needs Refresh" 的提示，表示權限已失效。這可能在應用程式更新或重新建置後發生。

**修復方法：**

1. 打開 **System Settings > Privacy & Security > Accessibility**。
2. 在列表中找到 **"Window Resize"**。
3. 將其 **關閉**，然後重新 **開啟**。
4. 或者，將其從列表中完全移除，然後重新啟動應用程式以重新加入。

### 吸附不起作用

如果調整大小時覆蓋框未出現：

- 確認輔助使用權限已啟用（設定中為綠色指示器）。
- 確保您調整大小的視窗支援標準調整大小操作（部分應用程式會限制視窗大小調整）。
- 全螢幕視窗無法調整大小——請先退出全螢幕。
- 檢查 Presets 標籤頁——目標大小可能已被停用。

### 吸附後視窗顯示異常

在極少數情況下，目標視窗在吸附後可能無法正確重繪。應用程式會自動強制重繪，但如果視覺殘影持續存在，請嘗試將視窗最小化後再還原。
