## 初始設定

### 授予輔助使用權限

Window Resize 使用 macOS 輔助使用 API 來偵測和調整視窗大小。首次啟動時需要授予權限。

1. 啟動 **Window Resize**。系統會彈出對話框，要求您授予輔助使用存取權限。
2. 點擊 **「打開系統設定」**（或手動前往 **系統設定 > 隱私權與安全性 > 輔助使用**）。
3. 在列表中找到 **「Window Resize」**，打開開關。
4. 返回應用程式——選單列圖示將出現，應用程式即可使用。

> **注意：** 如果對話框未出現，您可以從應用程式的設定視窗直接打開輔助使用設定（請參閱[輔助使用狀態](#輔助使用狀態)）。

## 吸附調整大小

### 運作方式

Window Resize 會即時監控視窗的調整大小操作。當您拖曳視窗邊緣或角落來調整大小時，應用程式會偵測視窗尺寸與預設大小的接近程度。

1. **開始調整大小** — 像平常一樣拖曳任何視窗的邊緣或角落。
2. **覆蓋框出現** — 當視窗大小接近某個預設大小（在 30 像素範圍內）時，視窗周圍會出現彩色邊框覆蓋框，顯示目標預設大小。
3. **放開滑鼠以吸附** — 鬆開滑鼠，視窗即會精確吸附到該預設大小。
4. **取消** — 如果在放開滑鼠前將視窗大小移離預設範圍，覆蓋框會消失，不會進行吸附。

### 長寬比顯示

調整大小時，覆蓋框中會顯示目前的長寬比。當比例與知名比例相符時，會顯示其名稱：

- **黃金比** (1.618:1)
- **白銀比** (2.414:1)
- **白金比** (1.325:1)
- **青銅比** (3.303:1)

其他比例則以簡化分數顯示（例如「16:9」、「4:3」）。

> 此功能可在設定中關閉（請參閱[覆蓋框外觀](#覆蓋框外觀)）。

### Shift 鍵鎖定長寬比

調整大小時按住 **Shift** 鍵即可鎖定長寬比。拖曳時視窗會維持目前的比例。

> 此功能可在設定中關閉（請參閱[覆蓋框外觀](#覆蓋框外觀)）。

## 設定

從選單列打開設定：點擊 Window Resize 圖示，然後選擇 **「設定⋯」**（快速鍵：**⌘,**）。

### 內建大小

應用程式包含 12 個內建預設大小：

| 大小 | 標籤 |
|------|------|
| 2560 x 1600 | MacBook Pro 16" |
| 2560 x 1440 | QHD / iMac |
| 1728 x 1117 | MacBook Pro 14" |
| 1512 x 982 | MacBook Air 15" |
| 1470 x 956 | MacBook Air 13" M3 |
| 1440 x 900 | MacBook Air 13" |
| 1920 x 1080 | Full HD |
| 1680 x 1050 | WSXGA+ |
| 1280 x 800 | WXGA |
| 1280 x 720 | HD |
| 1024 x 768 | XGA |
| 800 x 600 | SVGA |

內建大小無法移除或編輯。

### 自訂大小

您可以向列表中加入自己的大小：

1. 在 **「自訂」** 部分，輸入 **寬度** 和 **高度**（以像素為單位）。
2. 點擊 **「加入」**。
3. 新大小會立即生效，可在調整大小時用於吸附偵測。

要移除自訂大小，請點擊旁邊紅色的 **「移除」** 按鈕。

### 覆蓋框外觀

設定吸附覆蓋框的視覺樣式：

- **調整大小邊框** — 調整大小接近預設時顯示的邊框顏色和線條樣式（實線或虛線）。預設值：橘色、虛線。
- **吸附邊框** — 視窗吸附到預設時顯示的邊框顏色和線條樣式。預設值：橘色、實線。
- **顯示長寬比** — 切換覆蓋框中長寬比標籤的顯示。預設值：開啟。
- **Shift 鍵鎖定比例** — 切換按住 Shift 鍵時是否鎖定長寬比。預設值：開啟。

可選邊框顏色：橘色、藍色、綠色、紅色、紫色、白色。

### 登入時啟動

打開 **「登入時啟動」** 開關，可讓 Window Resize 在您登入 macOS 時自動啟動。

### 語言

從 **「語言」** 下拉選單中選擇應用程式的顯示語言。可從 16 種語言中選擇，或選擇 **「系統預設」** 以跟隨 macOS 系統語言。更改語言後需要重新啟動應用程式。

### 輔助使用狀態

在設定視窗底部，狀態指示器顯示輔助使用權限的目前狀態：

| 指示器 | 含義 |
|--------|------|
| 綠色 | 權限已啟用且運作正常。 |
| 橘色 | 系統報告權限已授予，但已失效（請參閱[修復失效權限](#修復失效權限)）。會顯示「打開設定」按鈕。 |
| 紅色 | 權限尚未授予。會顯示「打開設定」按鈕。 |

## 疑難排解

### 修復失效權限

如果您看到橘色狀態指示器或「輔助使用：需要重新整理」的提示，表示權限已失效。這可能在應用程式更新或重新建置後發生。

**修復方法：**

1. 打開 **系統設定 > 隱私權與安全性 > 輔助使用**。
2. 在列表中找到 **「Window Resize」**。
3. 將其 **關閉**，然後重新 **開啟**。
4. 或者，將其從列表中完全移除，然後重新啟動應用程式以重新加入。

### 吸附不起作用

如果調整大小時覆蓋框未出現：

- 確認輔助使用權限已啟用（設定中為綠色指示器）。
- 確保您調整大小的視窗支援標準調整大小操作（部分應用程式會限制視窗大小調整）。
- 全螢幕視窗無法調整大小——請先退出全螢幕。

### 吸附後視窗顯示異常

在極少數情況下，目標視窗在吸附後可能無法正確重繪。應用程式會自動強制重繪，但如果視覺殘影持續存在，請嘗試將視窗最小化後再還原。
