## การตั้งค่าเริ่มต้น

### การให้สิทธิ์การช่วยการเข้าถึง

Window Resize ใช้ API การช่วยการเข้าถึงของ macOS เพื่อตรวจจับและปรับขนาดหน้าต่าง คุณต้องให้สิทธิ์เมื่อเปิดใช้งานแอปครั้งแรก

1. เปิด **Window Resize** จะปรากฏกล่องโต้ตอบของระบบขอให้คุณอนุญาตการเข้าถึงการช่วยการเข้าถึง
2. คลิก **"เปิดการตั้งค่าระบบ"** (หรือไปที่ **การตั้งค่าระบบ > ความเป็นส่วนตัวและความปลอดภัย > การช่วยการเข้าถึง** ด้วยตนเอง)
3. ค้นหา **"Window Resize"** ในรายการและเปิดสวิตช์
4. กลับไปที่แอป — ไอคอนแถบเมนูจะปรากฏขึ้นและแอปพร้อมใช้งาน

> **หมายเหตุ:** หากกล่องโต้ตอบไม่ปรากฏ คุณสามารถเปิดการตั้งค่าการช่วยการเข้าถึงได้โดยตรงจากหน้าต่างการตั้งค่าของแอป (ดู [สถานะการช่วยการเข้าถึง](#สถานะการช่วยการเข้าถึง))

## สแนปปรับขนาด

### วิธีการทำงาน

Window Resize ตรวจสอบการปรับขนาดหน้าต่างแบบเรียลไทม์ เมื่อคุณลากขอบหรือมุมของหน้าต่างเพื่อปรับขนาด แอปจะตรวจจับว่าขนาดหน้าต่างใกล้เคียงกับขนาดที่ตั้งไว้ล่วงหน้ามากน้อยเพียงใด

1. **เริ่มปรับขนาด** — ลากขอบหรือมุมของหน้าต่างใดก็ได้ตามปกติ
2. **โอเวอร์เลย์ปรากฏ** — เมื่อขนาดหน้าต่างเข้าใกล้ขนาดที่ตั้งไว้ล่วงหน้า (ภายใน 30 พิกเซล) โอเวอร์เลย์เส้นขอบสีจะปรากฏรอบหน้าต่างพร้อมแสดงขนาดเป้าหมาย
3. **ปล่อยเพื่อสแนป** — ปล่อยเมาส์แล้วหน้าต่างจะปรับขนาดตรงกับขนาดที่ตั้งไว้ล่วงหน้าอย่างแม่นยำ
4. **ยกเลิก** — หากคุณลากขนาดหน้าต่างออกห่างจากขนาดที่ตั้งไว้ก่อนปล่อย โอเวอร์เลย์จะหายไปและไม่มีการสแนปเกิดขึ้น

### การแสดงอัตราส่วนภาพ

ระหว่างการปรับขนาด อัตราส่วนภาพปัจจุบันจะแสดงในโอเวอร์เลย์ เมื่ออัตราส่วนตรงกับสัดส่วนที่เป็นที่รู้จัก จะแสดงชื่อของอัตราส่วนนั้น:

- **อัตราส่วนทอง** (1.618:1)
- **อัตราส่วนเงิน** (2.414:1)
- **อัตราส่วนแพลทินัม** (1.325:1)
- **อัตราส่วนทองแดง** (3.303:1)

อัตราส่วนอื่นๆ จะแสดงเป็นเศษส่วนอย่างง่าย (เช่น "16:9", "4:3")

> คุณสมบัตินี้สามารถปิดได้ในการตั้งค่า (ดู [แสดงอัตราส่วนภาพ](#รูปแบบโอเวอร์เลย์))

### กดปุ่ม Shift เพื่อล็อกอัตราส่วนภาพ

กดปุ่ม **Shift** ค้างไว้ระหว่างปรับขนาดเพื่อล็อกอัตราส่วนภาพ หน้าต่างจะรักษาสัดส่วนปัจจุบันไว้ขณะที่คุณลาก

> คุณสมบัตินี้สามารถปิดได้ในการตั้งค่า (ดู [Shift ล็อกอัตราส่วน](#รูปแบบโอเวอร์เลย์))

## การตั้งค่า

เปิดการตั้งค่าจากแถบเมนู: คลิกไอคอน Window Resize จากนั้นเลือก **"การตั้งค่า..."** (ทางลัด: **Cmd+,**)

### ขนาดในตัว

แอปมีขนาดที่ตั้งไว้ในตัว 12 ขนาด:

| ขนาด | ป้ายชื่อ |
|------|----------|
| 2560 x 1600 | MacBook Pro 16" |
| 2560 x 1440 | QHD / iMac |
| 1728 x 1117 | MacBook Pro 14" |
| 1512 x 982 | MacBook Air 15" |
| 1470 x 956 | MacBook Air 13" M3 |
| 1440 x 900 | MacBook Air 13" |
| 1920 x 1080 | Full HD |
| 1680 x 1050 | WSXGA+ |
| 1280 x 800 | WXGA |
| 1280 x 720 | HD |
| 1024 x 768 | XGA |
| 800 x 600 | SVGA |

ขนาดในตัวไม่สามารถลบหรือแก้ไขได้

### ขนาดกำหนดเอง

คุณสามารถเพิ่มขนาดของคุณเองลงในรายการ:

1. ในส่วน **"กำหนดเอง"** ให้ป้อน **ความกว้าง** และ **ความสูง** เป็นพิกเซล
2. คลิก **"เพิ่ม"**
3. ขนาดใหม่จะพร้อมใช้งานทันทีสำหรับการตรวจจับสแนประหว่างการปรับขนาด

หากต้องการลบขนาดกำหนดเอง ให้คลิกปุ่ม **"ลบ"** สีแดงที่อยู่ถัดจากรายการนั้น

### รูปแบบโอเวอร์เลย์

กำหนดค่ารูปแบบการแสดงผลของโอเวอร์เลย์สแนป:

- **เส้นขอบปรับขนาด** — สีเส้นขอบและรูปแบบเส้น (ทึบหรือเส้นประ) ที่แสดงเมื่อปรับขนาดใกล้ขนาดที่ตั้งไว้ ค่าเริ่มต้น: สีส้ม, เส้นประ
- **เส้นขอบสแนป** — สีเส้นขอบและรูปแบบเส้นที่แสดงเมื่อหน้าต่างสแนปเข้ากับขนาดที่ตั้งไว้ ค่าเริ่มต้น: สีส้ม, ทึบ
- **แสดงอัตราส่วนภาพ** — เปิด/ปิดการแสดงป้ายอัตราส่วนภาพในโอเวอร์เลย์ ค่าเริ่มต้น: เปิด
- **Shift ล็อกอัตราส่วน** — เปิด/ปิดการใช้ปุ่ม Shift เพื่อล็อกอัตราส่วนภาพระหว่างปรับขนาด ค่าเริ่มต้น: เปิด

สีเส้นขอบที่เลือกได้: ส้ม, น้ำเงิน, เขียว, แดง, ม่วง, ขาว

### เปิดเมื่อเข้าสู่ระบบ

เปิด **"เปิดเมื่อเข้าสู่ระบบ"** เพื่อให้ Window Resize เริ่มทำงานโดยอัตโนมัติเมื่อคุณเข้าสู่ระบบ macOS

### ภาษา

เลือกภาษาที่แสดงในแอปจากเมนูดรอปดาวน์ **ภาษา** เลือกจาก 16 ภาษา หรือเลือก **"ค่าเริ่มต้นของระบบ"** เพื่อใช้ภาษาตามการตั้งค่าระบบ macOS การเปลี่ยนภาษาจะมีผลหลังจากเปิดแอปใหม่

### สถานะการช่วยการเข้าถึง

ที่ด้านล่างของหน้าต่างการตั้งค่า ตัวบ่งชี้สถานะจะแสดงสถานะปัจจุบันของสิทธิ์การช่วยการเข้าถึง:

| ตัวบ่งชี้ | ความหมาย |
|-----------|----------|
| สีเขียว | สิทธิ์ใช้งานได้และทำงานอย่างถูกต้อง |
| สีส้ม | ระบบรายงานว่าได้รับสิทธิ์แล้ว แต่ไม่สามารถใช้งานได้อีกต่อไป (ดู [การแก้ไขสิทธิ์ที่หมดอายุ](#การแก้ไขสิทธิ์ที่หมดอายุ)) ปุ่ม "เปิดการตั้งค่า" จะแสดงขึ้น |
| สีแดง | ยังไม่ได้ให้สิทธิ์ ปุ่ม "เปิดการตั้งค่า" จะแสดงขึ้น |

## การแก้ไขปัญหา

### การแก้ไขสิทธิ์ที่หมดอายุ

หากคุณเห็นตัวบ่งชี้สถานะสีส้มหรือข้อความ "การช่วยการเข้าถึง: ต้องรีเฟรช" แสดงว่าสิทธิ์หมดอายุแล้ว สิ่งนี้อาจเกิดขึ้นหลังจากแอปได้รับการอัปเดตหรือถูกบิลด์ใหม่

**วิธีแก้ไข:**

1. เปิด **การตั้งค่าระบบ > ความเป็นส่วนตัวและความปลอดภัย > การช่วยการเข้าถึง**
2. ค้นหา **"Window Resize"** ในรายการ
3. **ปิด** สวิตช์ จากนั้น **เปิด** อีกครั้ง
4. หรือลบออกจากรายการทั้งหมด จากนั้นเปิดแอปอีกครั้งเพื่อเพิ่มกลับ

### สแนปไม่ทำงาน

หากโอเวอร์เลย์ไม่ปรากฏระหว่างการปรับขนาด:

- ตรวจสอบว่าสิทธิ์การช่วยการเข้าถึงใช้งานได้ (ตัวบ่งชี้สีเขียวในการตั้งค่า)
- ตรวจสอบว่าหน้าต่างที่คุณกำลังปรับขนาดรองรับการปรับขนาดมาตรฐาน (แอปบางตัวจำกัดการปรับขนาดหน้าต่าง)
- หน้าต่างแบบเต็มหน้าจอไม่สามารถปรับขนาดได้ — ออกจากโหมดเต็มหน้าจอก่อน

### ปัญหาการแสดงผลหน้าต่างหลังสแนป

ในบางกรณี หน้าต่างเป้าหมายอาจไม่วาดใหม่อย่างถูกต้องหลังจากสแนป แอปจะบังคับให้วาดใหม่โดยอัตโนมัติ แต่หากปัญหาการแสดงผลยังคงอยู่ ให้ลองย่อหน้าต่างลงแล้วกลับคืน
