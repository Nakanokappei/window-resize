## 初始设置

### 授予辅助功能权限

Window Resize 使用 macOS 辅助功能 API 来检测和调整窗口大小。首次启动时需要授予权限。

1. 启动 **Window Resize**。系统会弹出对话框，要求您授予辅助功能访问权限。
2. 点击 **"打开系统设置"**（或手动前往 **系统设置 > 隐私与安全性 > 辅助功能**）。
3. 在列表中找到 **"Window Resize"**，打开开关。
4. 返回应用——菜单栏图标将出现，应用即可使用。

> **注意：** 如果对话框未出现，您可以从应用的设置窗口直接打开辅助功能设置（请参阅[辅助功能状态](#辅助功能状态)）。

## 吸附调整

### 工作原理

Window Resize 实时监控窗口的调整操作。当您拖动窗口的边缘或角落来调整大小时，应用会检测窗口尺寸与各预设大小的接近程度。

1. **开始调整** — 像平常一样拖动任意窗口的边缘或角落。
2. **覆盖层出现** — 当窗口大小接近某个预设（30 像素以内）时，窗口周围会出现带颜色的边框覆盖层，显示目标预设大小。
3. **释放以吸附** — 松开鼠标，窗口将精确吸附到预设大小。
4. **取消** — 如果在释放鼠标前将窗口大小移离预设范围，覆盖层会消失，不会发生吸附。

### 宽高比显示

在调整大小时，覆盖层中会显示当前的宽高比。当比例与已知的经典比例匹配时，会显示其名称：

- **黄金比** (1.618:1)
- **白银比** (2.414:1)
- **白金比** (1.325:1)
- **青铜比** (3.303:1)

其他比例以简化分数形式显示（例如 "16:9"、"4:3"）。

> 此功能可在设置中关闭（请参阅[覆盖层外观](#覆盖层外观)）。

### Shift 键锁定宽高比

在调整大小时按住 **Shift** 键可锁定宽高比。拖动时窗口将保持当前比例不变。

> 此功能可在设置中关闭（请参阅[覆盖层外观](#覆盖层外观)）。

## 设置

从菜单栏打开设置：点击 Window Resize 图标，然后选择 **"设置..."**（快捷键：**⌘,**）。

### 内置大小

应用包含 12 个内置预设大小：

| 大小 | 标签 |
|------|------|
| 2560 x 1600 | MacBook Pro 16" |
| 2560 x 1440 | QHD / iMac |
| 1728 x 1117 | MacBook Pro 14" |
| 1512 x 982 | MacBook Air 15" |
| 1470 x 956 | MacBook Air 13" M3 |
| 1440 x 900 | MacBook Air 13" |
| 1920 x 1080 | Full HD |
| 1680 x 1050 | WSXGA+ |
| 1280 x 800 | WXGA |
| 1280 x 720 | HD |
| 1024 x 768 | XGA |
| 800 x 600 | SVGA |

内置大小无法移除或编辑。

### 自定义大小

您可以向列表中添加自己的大小：

1. 在 **"自定义"** 部分，输入 **宽度** 和 **高度**（以像素为单位）。
2. 点击 **"添加"**。
3. 新大小立即可用于调整大小时的吸附检测。

要移除自定义大小，请点击旁边红色的 **"移除"** 按钮。

### 覆盖层外观

配置吸附覆盖层的视觉样式：

- **调整边框** — 调整大小接近预设时显示的边框颜色和线条样式（实线或虚线）。默认：橙色，虚线。
- **吸附边框** — 窗口吸附到预设时显示的边框颜色和线条样式。默认：橙色，实线。
- **显示宽高比** — 切换覆盖层中宽高比标签的显示。默认：开启。
- **Shift 键锁定比例** — 切换调整大小时按住 Shift 键是否锁定宽高比。默认：开启。

可选边框颜色：橙色、蓝色、绿色、红色、紫色、白色。

### 登录时启动

打开 **"登录时启动"** 开关，可让 Window Resize 在您登录 macOS 时自动启动。

### 语言

从 **"语言"** 下拉菜单中选择应用的显示语言。可从 16 种语言中选择，或选择 **"跟随系统"** 以使用 macOS 的系统语言。更改语言后需要重新启动应用。

### 辅助功能状态

在设置窗口底部，状态指示器显示辅助功能权限的当前状态：

| 指示器 | 含义 |
|--------|------|
| 绿色 | 权限已激活且工作正常。 |
| 橙色 | 系统报告权限已授予，但已失效（请参阅[修复失效权限](#修复失效权限)）。会显示 **"打开设置"** 按钮。 |
| 红色 | 权限尚未授予。会显示 **"打开设置"** 按钮。 |

## 故障排除

### 修复失效权限

如果您看到橙色状态指示器或"辅助功能：需要刷新"的提示，说明权限已失效。这可能在应用更新或重新构建后发生。

**修复方法：**

1. 打开 **系统设置 > 隐私与安全性 > 辅助功能**。
2. 在列表中找到 **"Window Resize"**。
3. 将其 **关闭**，然后重新 **打开**。
4. 或者，将其从列表中完全移除，然后重新启动应用以重新添加。

### 吸附不工作

如果调整大小时覆盖层未出现：

- 检查辅助功能权限是否已激活（设置中的绿色指示器）。
- 确保您正在调整的窗口支持标准调整大小操作（某些应用限制窗口大小调整）。
- 全屏窗口无法调整大小——请先退出全屏模式。

### 吸附后窗口显示异常

在极少数情况下，目标窗口在吸附后可能无法正确重绘。应用会自动强制重绘，但如果视觉问题持续存在，请尝试最小化后再恢复窗口。
