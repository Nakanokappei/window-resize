## 初始设置

### 授予辅助功能权限

Window Resize 使用 macOS 辅助功能 API 来检测和调整窗口大小。首次启动时需要授予权限。

1. 启动 **Window Resize**。系统会弹出对话框，要求您授予辅助功能访问权限。
2. 点击 **"Open System Settings"**（或手动前往 **System Settings > Privacy & Security > Accessibility**）。
3. 在列表中找到 **"Window Resize"**，打开开关。
4. 返回应用——菜单栏图标将出现，应用即可使用。

> **注意：** 如果对话框未出现，您可以从应用的设置窗口直接打开辅助功能设置（请参阅[辅助功能状态](#辅助功能状态)）。

## 吸附调整

### 工作原理

Window Resize 实时监控窗口的调整操作。当您拖动窗口的边缘或角落来调整大小时，应用会检测窗口尺寸与各预设大小的接近程度。

1. **开始调整** — 像平常一样拖动任意窗口的边缘或角落。
2. **覆盖层出现** — 当窗口大小接近某个预设（30 像素以内）时，窗口周围会出现带颜色的边框覆盖层，显示目标预设大小。
3. **释放以吸附** — 松开鼠标，窗口将精确吸附到预设大小。
4. **取消** — 如果在释放鼠标前将窗口大小移离预设范围，覆盖层会消失，不会发生吸附。

### 移动吸附

将窗口拖向屏幕边缘或角落以吸附到位：

- **边缘吸附**（左/右）— 填满高度，保持宽度
- **边缘吸附**（上/下）— 填满宽度，保持高度
- **角落吸附** — 将窗口定位到角落，保持宽高不变

### 宽高比显示

在调整大小时，覆盖层中会显示当前的宽高比。当比例与已知的经典比例匹配时，会显示其名称：

- **Golden Ratio** (1.618:1)
- **Silver Ratio** (2.414:1)
- **Platinum Ratio** (1.325:1)
- **Bronze Ratio** (3.303:1)

其他比例以简化分数形式显示（例如 "16:9"、"4:3"）。

> 此功能可在设置中关闭（请参阅[覆盖层外观](#外观标签页)）。

### Shift 键锁定宽高比

在调整大小时按住 **Shift** 键可锁定宽高比。拖动时窗口将保持当前比例不变。

> 此功能可在设置中关闭（请参阅[覆盖层外观](#外观标签页)）。

## 键盘快捷键

所有键盘快捷键均可在设置的 Shortcuts 标签页中自定义。默认设置：

### Quick Presets

按 **Control+Option+1** 至 **Control+Option+9** 可立即将最前方窗口调整为指定的预设大小。居中 HUD 会短暂显示预设名称和大小。

| 快捷键 | 默认预设 |
|----------|---------------|
| Control+Option+1 | Writing (1280 x 800) |
| Control+Option+2 | Reading (900 x 1200) |
| Control+Option+3 | Browsing (1440 x 900) |
| Control+Option+4 | Sidebar (720 x 900) |
| Control+Option+5 | Preview (1920 x 1080) |

Quick Presets 可在设置的 General 标签页中编辑（名称、大小和快捷键）。最多支持 9 个预设。

### 逐步调整

每次按键调整最前方窗口 10 像素，保持窗口居中：

| 快捷键 | 操作 |
|----------|--------|
| Control+Option+Right | 增加宽度 (+10px) |
| Control+Option+Left | 减少宽度 (-10px) |
| Control+Option+Up | 增加高度 (+10px) |
| Control+Option+Down | 减少高度 (-10px) |

### 精确模式

按住 Shift 进行 1 像素调整：

| 快捷键 | 操作 |
|----------|--------|
| Control+Option+Shift+Right | 增加宽度 (+1px) |
| Control+Option+Shift+Left | 减少宽度 (-1px) |
| Control+Option+Shift+Up | 增加高度 (+1px) |
| Control+Option+Shift+Down | 减少高度 (-1px) |

### 撤销 / 重做

| 快捷键 | 操作 |
|----------|--------|
| Control+Option+Z | 撤销上次调整 |
| Control+Option+Shift+Z | 重做 |

每个窗口维护各自的撤销/重做历史记录。

### HUD 反馈

使用键盘快捷键时，目标窗口中央会出现胶囊形 HUD：

- **Quick Preset：** 显示预设名称（如 "Writing"），下方显示大小（如 "1280 x 800"）
- **逐步调整：** 显示当前大小（如 "1290 x 800"）
- **撤销：** 显示 "Restored" 及恢复后的大小

HUD 显示 0.8 秒后淡出。

## 设置

从菜单栏打开设置：点击 Window Resize 图标，然后选择 **"Settings..."**。

设置分为 4 个标签页：**General**、**Appearance**、**Shortcuts** 和 **Presets**。

### General 标签页

#### Quick Presets

配置最多 9 个 Quick Presets，可通过键盘快捷键（Control+Option+1-9）应用。每个预设包含：

- **快捷键** — 点击快捷键字段以录制新的组合键
- **名称** — 描述性名称（如 "Writing"、"Coding"）
- **大小** — 宽度和高度（以像素为单位）

要添加预设，请在底部字段中填入名称、宽度和高度，然后点击 **"Add"**。要删除预设，请点击旁边的 X 按钮。

#### 登录时启动

打开 **"Launch at Login"** 开关，可让 Window Resize 在您登录 macOS 时自动启动。

#### 语言

从下拉菜单中选择应用的显示语言。可从 16 种语言中选择，或选择 **"System Default"** 以使用 macOS 的系统语言。更改语言后需要重新启动应用。

#### 辅助功能状态

状态指示器显示辅助功能权限的当前状态：

| 指示器 | 含义 |
|--------|------|
| 绿色 | 权限已激活且工作正常。 |
| 橙色 | 权限已授予但已失效（请参阅[修复失效权限](#修复失效权限)）。 |
| 红色 | 权限尚未授予。 |

### 外观标签页

配置吸附覆盖层的视觉样式：

- **调整边框** — 调整大小时显示的边框颜色和线条样式。可从 9 种颜色（红色、橙色、黄色、绿色、青色、蓝色、紫色、白色、灰色）和 4 种样式（无、实线、虚线、动画）中选择。默认：白色、动画。
- **吸附边框** — 窗口吸附到预设时显示的边框。默认：白色、实线。
- **显示宽高比** — 切换覆盖层中宽高比标签的显示。默认：开启。
- **Shift 键锁定比例** — 切换调整大小时按住 Shift 键是否锁定宽高比。默认：开启。

### Shortcuts 标签页

所有键盘快捷键以 2 列网格显示，可逐个自定义：

1. 点击任意操作旁边的快捷键字段。
2. 按下所需的组合键（必须包含至少一个修饰键）。
3. 按 **Escape** 取消录制。

如果您录制的快捷键与应用中其他操作冲突，会出现警告对话框，提供 **Replace**（重新分配快捷键）或 **Cancel** 选项。

与已知系统快捷键（Mission Control、Spotlight 等）冲突的快捷键旁会显示警告图标。

点击 **"Reset to Defaults"** 可将所有快捷键恢复为默认值。

### Presets 标签页

Presets 标签页显示 18 个内置预设大小，按像素面积排序（从小到大）。每个预设有启用/禁用开关：

- **已启用** — 该预设用于调整大小时的吸附检测
- **已禁用** — 该预设被排除在吸附检测之外（以 50% 不透明度显示）

内置预设无法删除，只能禁用。默认情况下，6 个 Mac 专用预设（MacBook Air/Pro 显示器大小）被禁用，12 个通用预设被启用。

页眉显示当前启用的预设数量（如 "12 of 18 enabled"）。

## 故障排除

### 修复失效权限

如果您看到橙色状态指示器或 "Accessibility: Needs Refresh" 的提示，说明权限已失效。这可能在应用更新或重新构建后发生。

**修复方法：**

1. 打开 **System Settings > Privacy & Security > Accessibility**。
2. 在列表中找到 **"Window Resize"**。
3. 将其 **关闭**，然后重新 **打开**。
4. 或者，将其从列表中完全移除，然后重新启动应用以重新添加。

### 吸附不工作

如果调整大小时覆盖层未出现：

- 检查辅助功能权限是否已激活（设置中的绿色指示器）。
- 确保您正在调整的窗口支持标准调整大小操作（某些应用限制窗口大小调整）。
- 全屏窗口无法调整大小——请先退出全屏模式。
- 检查 Presets 标签页——目标大小可能已被禁用。

### 吸附后窗口显示异常

在极少数情况下，目标窗口在吸附后可能无法正确重绘。应用会自动强制重绘，但如果视觉问题持续存在，请尝试最小化后再恢复窗口。
