## 初期設定

### アクセシビリティ権限の付与

Window Resize は macOS のアクセシビリティ API を使用してウインドウの検出とリサイズを行います。初回起動時に権限を付与する必要があります。

1. **Window Resize** を起動します。アクセシビリティへのアクセスを求めるシステムダイアログが表示されます。
2. **「設定を開く」** をクリックします（または手動で **システム設定 > プライバシーとセキュリティ > アクセシビリティ** を開きます）。
3. 一覧から **「Window Resize」** を見つけ、トグルをオンにします。
4. アプリに戻ると、メニューバーにアイコンが表示され、使用可能になります。

> **注意:** ダイアログが表示されない場合は、設定画面から直接アクセシビリティ設定を開くことができます（[アクセシビリティの状態](#アクセシビリティの状態) を参照）。

## スナップリサイズ

### 仕組み

Window Resize はウインドウのリサイズ操作をリアルタイムで監視します。ウインドウの端やコーナーをドラッグしてリサイズすると、ウインドウのサイズがプリセットサイズにどれだけ近いかを検出します。

1. **リサイズを開始** — 通常通り、ウインドウの端やコーナーをドラッグします。
2. **オーバーレイが表示** — ウインドウサイズがプリセットに近づくと（50ピクセル以内）、色付きの枠線オーバーレイがウインドウの周囲に表示され、スナップ先のプリセットサイズが示されます。
3. **離してスナップ** — マウスを離すと、ウインドウがプリセットサイズに正確にスナップします。
4. **キャンセル** — マウスを離す前にプリセットサイズから離れると、オーバーレイが消えてスナップは行われません。

### アスペクト比の表示

リサイズ中、現在のアスペクト比がオーバーレイに表示されます。よく知られた比率に一致する場合、その名前が表示されます。

- **√2** (1.414:1)
- **黄金比** (1.618:1)
- **白銀比** (2.414:1)
- **白金比** (1.325:1)
- **青銅比** (3.303:1)

その他の比率は簡約された分数で表示されます（例: 「16:9」、「4:3」）。

> この機能は設定でオフにできます（[外観タブ](#外観タブ) を参照）。

### Shiftキーでアスペクト比を固定

リサイズ中に **Shift** キーを押し続けると、アスペクト比が固定されます。ドラッグ中もウインドウの現在の比率が維持されます。

> この機能は設定でオフにできます（[全般タブ](#全般タブ) を参照）。

## キーボードショートカット

すべてのキーボードショートカットは設定の「ショートカット」タブで自由にカスタマイズできます。デフォルト:

### クイックプリセット

**Control+Option+1** 〜 **Control+Option+9** で最前面のウインドウを指定のプリセットサイズに即座にリサイズします。ウインドウ中央にHUDでプリセット名とサイズが表示されます。

| ショートカット | デフォルトプリセット |
|--------------|-------------------|
| Control+Option+1 | Writing (1280 x 800) |
| Control+Option+2 | Reading (900 x 1200) |
| Control+Option+3 | Browsing (1440 x 900) |
| Control+Option+4 | Sidebar (720 x 900) |
| Control+Option+5 | Preview (1920 x 1080) |

クイックプリセットは「全般」タブでラベル・サイズ・ショートカットを編集できます。最大9個まで設定可能です。

### インクリメンタルリサイズ

最前面のウインドウを1キーにつき10ピクセルずつリサイズします。ウインドウは中央に固定されます。

| ショートカット | 動作 |
|--------------|------|
| Control+Option+→ | 幅を拡大 (+10px) |
| Control+Option+← | 幅を縮小 (-10px) |
| Control+Option+↑ | 高さを拡大 (+10px) |
| Control+Option+↓ | 高さを縮小 (-10px) |

### 精密モード

Shiftを追加すると1ピクセル単位で調整できます。

| ショートカット | 動作 |
|--------------|------|
| Control+Option+Shift+→ | 幅を拡大 (+1px) |
| Control+Option+Shift+← | 幅を縮小 (-1px) |
| Control+Option+Shift+↑ | 高さを拡大 (+1px) |
| Control+Option+Shift+↓ | 高さを縮小 (-1px) |

### 元に戻す / やり直す

| ショートカット | 動作 |
|--------------|------|
| Control+Option+Z | 元に戻す |
| Control+Option+Shift+Z | やり直す |

各ウインドウごとに独立した元に戻す/やり直す履歴を持ちます。

### HUDフィードバック

キーボードショートカットを使用すると、対象ウインドウの中央にHUDピルが表示されます。

- **クイックプリセット:** プリセット名（例: "Writing"）を主表示、サイズ（例: "1280 x 800"）を副表示
- **インクリメンタルリサイズ:** 現在のサイズ（例: "1290 x 800"）を表示
- **元に戻す:** "Restored" と復元されたサイズを表示

HUDは0.8秒表示後、フェードアウトします。

## 設定

メニューバーの Window Resize アイコンをクリックし、**「設定...」** を選択して設定画面を開きます。

設定は4つのタブに分かれています: **全般**、**外観**、**ショートカット**、**プリセット**。

### 全般タブ

#### クイックプリセット

キーボードショートカット (Control+Option+1-9) で適用できるクイックプリセットを最大9個設定できます。各プリセットには以下があります:

- **ショートカット** — ショートカット欄をクリックして新しいキーの組み合わせを録音
- **ラベル** — 用途を示す名前（例: "Writing"、"Coding"）
- **サイズ** — 幅と高さ（ピクセル単位）

プリセットを追加するには、下部のラベル・幅・高さ欄を入力して **「追加」** をクリックします。削除するにはプリセット横の X ボタンをクリックします。

#### ログイン時に起動

**「ログイン時に起動」** をオンにすると、macOS にログインした際に自動起動します。

#### Shiftキーで比率固定

リサイズ中にShiftキーでアスペクト比を固定する機能の有効・無効を切り替えます。デフォルト: オン。

#### アクセシビリティの状態

権限の現在の状態を示すインジケーター:

| インジケーター | 意味 |
|----------------|------|
| 緑 | 権限が有効で正常動作中 |
| オレンジ | 権限は付与済みだが無効化（[修復方法](#権限が無効になった場合の修復方法) を参照） |
| 赤 | 権限が未付与 |

### 外観タブ

スナップオーバーレイの見た目をカスタマイズできます。

- **リサイズ枠線** — リサイズ中の枠線の色と線種。9色（赤、オレンジ、黄、緑、シアン、青、紫、白、灰）と4種類の線種（なし、実線、破線、アニメーション）から選択。デフォルト: オレンジ、アニメーション。
- **スナップ枠線** — スナップ時の枠線。デフォルト: オレンジ、実線。
- **アスペクト比を表示** — オーバーレイ内の比率ラベルの表示切替。デフォルト: オン。

### ショートカットタブ

すべてのキーボードショートカットが2列グリッドで表示され、個別にカスタマイズできます。

1. アクションの横にあるショートカット欄をクリックします。
2. 新しいキーの組み合わせを押します（修飾キーが1つ以上必要）。
3. **Escape** を押すと録音をキャンセルします。

アプリ内の別のアクションと同じショートカットを設定しようとすると、アラートダイアログが表示され、**「置き換える」**（旧ショートカットをクリア）または **「キャンセル」** を選択できます。

システムショートカット（Mission Control、Spotlightなど）と競合する場合は警告アイコンが表示されます。

**「デフォルトに戻す」** をクリックすると、すべてのショートカットを初期設定に復元します。

### プリセットタブ

18種類の内蔵プリセットサイズがピクセル面積の昇順で表示されます。各プリセットには有効/無効トグルがあります。

- **有効** — リサイズ時のスナップ検出対象
- **無効** — スナップ検出から除外（半透明で表示）

内蔵プリセットは削除できず、無効化のみ可能です。デフォルトでは Mac 固有の6プリセット（MacBook Air/Pro のディスプレイサイズ）が無効、汎用12プリセットが有効です。

ヘッダーに現在の有効数が表示されます（例: "12 / 18 有効"）。

## トラブルシューティング

### 権限が無効になった場合の修復方法

オレンジ色のインジケーターが表示される場合、権限が古くなっています。アプリのアップデートや再ビルド後に発生することがあります。

**修復手順:**

1. **システム設定 > プライバシーとセキュリティ > アクセシビリティ** を開きます。
2. 一覧から **「Window Resize」** を見つけます。
3. トグルを **オフ** にしてから、再度 **オン** にします。
4. または、一覧から完全に削除してからアプリを再起動します。

### スナップが動作しない

リサイズ中にオーバーレイが表示されない場合:

- アクセシビリティ権限が有効か確認してください（設定画面で緑のインジケーター）。
- リサイズ中のウインドウが標準のリサイズに対応しているか確認してください。
- フルスクリーンのウインドウはリサイズできません。先にフルスクリーンを解除してください。
- プリセットタブで対象のサイズが無効になっていないか確認してください。

### スナップ後のウインドウ描画の乱れ

まれに、スナップ後にウインドウが正しく再描画されないことがあります。表示の乱れが続く場合はウインドウを最小化してから復元してください。
