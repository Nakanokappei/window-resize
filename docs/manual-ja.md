## 初期設定

### アクセシビリティ権限の付与

Window Resize は macOS のアクセシビリティ API を使用してウインドウの検出とリサイズを行います。初回起動時に権限を付与する必要があります。

1. **Window Resize** を起動します。アクセシビリティへのアクセスを求めるシステムダイアログが表示されます。
2. **「設定を開く」** をクリックします（または手動で **システム設定 > プライバシーとセキュリティ > アクセシビリティ** を開きます）。
3. 一覧から **「Window Resize」** を見つけ、トグルをオンにします。
4. アプリに戻ると、メニューバーにアイコンが表示され、使用可能になります。

> **注意:** ダイアログが表示されない場合は、設定画面から直接アクセシビリティ設定を開くことができます（[アクセシビリティの状態](#アクセシビリティの状態) を参照）。

## スナップリサイズ

### 仕組み

Window Resize はウインドウのリサイズ操作をリアルタイムで監視します。ウインドウの端やコーナーをドラッグしてリサイズすると、ウインドウのサイズがプリセットサイズにどれだけ近いかを検出します。

1. **リサイズを開始** — 通常通り、ウインドウの端やコーナーをドラッグします。
2. **オーバーレイが表示** — ウインドウサイズがプリセットに近づくと（30ピクセル以内）、色付きの枠線オーバーレイがウインドウの周囲に表示され、スナップ先のプリセットサイズが示されます。
3. **離してスナップ** — マウスを離すと、ウインドウがプリセットサイズに正確にスナップします。
4. **キャンセル** — マウスを離す前にプリセットサイズから離れると、オーバーレイが消えてスナップは行われません。

### アスペクト比の表示

リサイズ中、現在のアスペクト比がオーバーレイに表示されます。よく知られた比率に一致する場合、その名前が表示されます。

- **黄金比** (1.618:1)
- **白銀比** (2.414:1)
- **白金比** (1.325:1)
- **青銅比** (3.303:1)

その他の比率は簡約された分数で表示されます（例: 「16:9」、「4:3」）。

> この機能は設定でオフにできます（[オーバーレイの外観](#オーバーレイの外観) を参照）。

### Shiftキーでアスペクト比を固定

リサイズ中に **Shift** キーを押し続けると、アスペクト比が固定されます。ドラッグ中もウインドウの現在の比率が維持されます。

> この機能は設定でオフにできます（[オーバーレイの外観](#オーバーレイの外観) を参照）。

## 設定

メニューバーの Window Resize アイコンをクリックし、**「設定...」** を選択して設定画面を開きます（ショートカット: **⌘,**）。

### 内蔵サイズ

アプリには 12 種類の内蔵プリセットサイズが含まれています。

| サイズ | ラベル |
|--------|--------|
| 2560 x 1600 | MacBook Pro 16" |
| 2560 x 1440 | QHD / iMac |
| 1728 x 1117 | MacBook Pro 14" |
| 1512 x 982 | MacBook Air 15" |
| 1470 x 956 | MacBook Air 13" M3 |
| 1440 x 900 | MacBook Air 13" |
| 1920 x 1080 | Full HD |
| 1680 x 1050 | WSXGA+ |
| 1280 x 800 | WXGA |
| 1280 x 720 | HD |
| 1024 x 768 | XGA |
| 800 x 600 | SVGA |

内蔵サイズは削除・編集できません。

### カスタムサイズ

独自のサイズを追加できます。

1. **「カスタム」** セクションで、**幅** と **高さ** をピクセル単位で入力します。
2. **「追加」** をクリックします。
3. 新しいサイズはすぐにリサイズ時のスナップ検出で利用可能になります。

カスタムサイズを削除するには、該当サイズの横にある赤い **「削除」** ボタンをクリックします。

### オーバーレイの外観

スナップオーバーレイの見た目をカスタマイズできます。

- **リサイズ枠線** — プリセット付近でリサイズ中に表示される枠線の色と線種（実線または破線）。デフォルト: オレンジ、破線。
- **スナップ枠線** — ウインドウがプリセットにスナップした際に表示される枠線の色と線種。デフォルト: オレンジ、実線。
- **アスペクト比を表示** — オーバーレイ内のアスペクト比ラベルの表示・非表示。デフォルト: オン。
- **Shiftキーで比率固定** — リサイズ中にShiftキーでアスペクト比を固定する機能の有効・無効。デフォルト: オン。

利用可能な枠線の色: オレンジ、青、緑、赤、紫、白。

### ログイン時に起動

**「ログイン時に起動」** をオンにすると、macOS にログインした際に Window Resize が自動的に起動します。

### 言語

**「言語」** ドロップダウンからアプリの表示言語を選択します。16 言語から選択するか、**「システムデフォルト」** を選択して macOS のシステム言語に従います。言語を変更するとアプリの再起動が必要です。

### アクセシビリティの状態

設定画面の下部に、アクセシビリティ権限の現在の状態を示すインジケーターがあります。

| インジケーター | 意味 |
|----------------|------|
| 🟢 緑 | 権限が有効で、正常に動作しています。 |
| 🟠 オレンジ | システム上は権限が付与されていますが、実際には無効になっています（[権限が無効になった場合の修復方法](#権限が無効になった場合の修復方法) を参照）。**「設定を開く」** ボタンが表示されます。 |
| 🔴 赤 | 権限が付与されていません。**「設定を開く」** ボタンが表示されます。 |

## トラブルシューティング

### 権限が無効になった場合の修復方法

オレンジ色のインジケーターや「アクセシビリティ：更新が必要」というメッセージが表示される場合、権限が古くなっています。これはアプリのアップデートや再ビルド後に発生することがあります。

**修復手順:**

1. **システム設定 > プライバシーとセキュリティ > アクセシビリティ** を開きます。
2. 一覧から **「Window Resize」** を見つけます。
3. トグルを **オフ** にしてから、再度 **オン** にします。
4. または、一覧から完全に削除してからアプリを再起動すると、再度追加できます。

### スナップが動作しない

リサイズ中にオーバーレイが表示されない場合:

- アクセシビリティ権限が有効か確認してください（設定画面で緑のインジケーター）。
- リサイズ中のウインドウが標準のリサイズに対応しているか確認してください（一部のアプリはウインドウサイズを制限しています）。
- フルスクリーンのウインドウはリサイズできません。先にフルスクリーンを解除してください。

### スナップ後のウインドウ描画の乱れ

まれに、スナップ後にウインドウが正しく再描画されないことがあります。アプリは自動的に再描画を強制しますが、表示の乱れが続く場合はウインドウを最小化してから復元してください。
